# Interactive Calendar Planner

An interactive web-based calendar application for task management. This project features a responsive monthly grid layout with drag-and-drop capabilities for rescheduling, dynamic task filtering, and public holiday integration.

## Features 

- **Dynamic Monthly Calendar:** Seamless navigation between months with auto-generated grid layout.
- **Task Management (CRUD):** Full support for creating, reading, updating, deleting, and reordering tasks.
- **Drag-and-Drop Scheduling:** Effortlessly move tasks between calendar days or reorder lists using `@dnd-kit`.
- **Instant Search & Filter:** Real-time case-insensitive task filtering.
- **Public Holiday Integration:** Automated fetching and rendering of official public holidays using the Nager.Date API.

## Tech Stack

- **Frontend:** React, TypeScript.
- **Drag-and-Drop:** `@dnd-kit/react`, `@dnd-kit/dom`.
- **State & Logic:** Custom hooks integrated with React Query for server-state management.
- **Backend:** Node.js, Express, TypeScript, Mongoose (MongoDB), Zod (Data Validation).
- **Icons:** `lucide-react`.
- **External API:** Nager.Date API
